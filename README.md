# TRADEVALUE

Progetto personale · Economia

Workspace personale di analisi dei mercati con agenti e dashboard.

## Esigenza

Rendere consultabili dati e analisi provenienti da più strumenti.

## Contributo

Ho integrato analisi, aggiornamenti e visualizzazione dei dati in un’applicazione web.

## Stack

Python, FastAPI, React, SSE, SQLite.

## Una scelta da raccontare

Progetto di ricerca personale; non dichiara rendimenti o risultati di investimento.
